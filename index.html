Installation

Add the stylesheet and script to your page. Both are served from this site with CORS enabled, so any domain can use them. Everything under /v1/ stays backwards compatible; breaking changes ship as /v2/.

Prefer a classic script (no modules)? Use ds.iife.js instead. Both expose the same API on window.DS.

Theming

Colors are defined with light-dark(), so the whole system follows the OS theme by default. Set data-theme="light" or data-theme="dark" on <html> to force one. Any button with data-theme-value switches and remembers the theme.

A .dropdown with a toggle (data-ds-toggle="dropdown") and a .menu. Closes on outside click, Esc or choosing an item. Use .dropdown-end to align right.

Scrollbars

Every scrollable area gets a thin, rounded scrollbar that follows the theme: no class needed. The thumb keeps a small gap from the edges, grows on hover and turns accent while dragged. Tune it with --scrollbar-size, --scrollbar-inset, --scrollbar-thumb, --scrollbar-thumb-hover and --scrollbar-thumb-active. Avoid setting scrollbar-width or scrollbar-color yourself: in Chrome that switches the custom style off.

.scroll-y

Scrolls vertically and keeps the scroll inside the box (no scroll chaining to the page).

JavaScript API

ds.js wires up behaviour through data attributes as soon as it loads; content added later works too. For anything else, use window.DS or import from the module:

FunctionDescription
DS.setTheme(theme, persist = true)'light', 'dark' or 'system'. Saved in localStorage['theme'].
DS.getTheme()The current theme setting.
DS.toast(message, options)Show a toast. Options: variant, duration (ms, 0 = sticky), action. Returns { dismiss }.
DS.openDialog(target) / DS.closeDialog(target, value)Open or close a <dialog> by selector or element.
DS.selectTab(tab)Select a tab and show its panel.
DS.syncRange(input?)Refresh the filled track of one range input, or all of them.
DS.versionLibrary version.

Data attributes

AttributeEffect
data-theme-value="light|dark|system"Click switches theme; gets aria-pressed.
data-ds-open="#dialog"Click opens that dialog.
data-ds-close="value"Click closes the surrounding dialog with that return value.
data-ds-dismissibleOn a dialog: close on backdrop click.
data-ds-dismissClick removes the surrounding .alert.
data-ds-toggle="dropdown"Toggle of a .dropdown.
data-ds-tabsOn a role="tablist": click and keyboard tab switching.
